# Pixel art system

Everything is generated by code — no sprite sheets or downloaded art. `apps/web/src/office/pixel/` has no DOM/Node
dependency, so the same drawing code runs in the browser (PixiJS textures) and in Node (`npm run assets` exports PNGs to
`apps/web/public/assets/` for review).

| File | Responsibility |
|---|---|
| `buffer.ts` | RGBA `PixelBuffer`: rect/line/ellipse/blit/outline/desaturate + deterministic RNG |
| `palette.ts` | One shared palette (warm white/gray/blue, cyan accents) so the world stays consistent |
| `characters.ts` | Modular 16x24 characters: head/hair (6 styles), 5 department outfits + owner, arms, legs, accessories; poses idle, walk, working, thinking, talking, meeting, resting (2-4 frames, 3 directions) |
| `icons.ts` | 10x10 status icons (waiting, blocked, paused, error, offline, unknown, starting, stopping + thinking/talk/zzz/meeting bubbles) |
| `layout.ts` | The ship: 64x34 tiles, 7 rooms, doors, corridor lane, seats, blockers, routing |
| `ship.ts` | Draws floors, walls, windows to space, and all furniture into one buffer; animated LED/screen lights |
| `../scene.ts` | PixiJS scene: actors, camera (zoom/pan), HUD text, WASD avatar |

## Truthfulness in the scene
The scene's *only* input about an agent is its `AgentDTO` (`placement.room/pose/overlay`, `state`, `mode`, `stale`).
Characters walk to the room the backend says they are in; offline/unknown agents are dimmed and never animated as working.
REAL = solid green ring + `REAL` tag; SIMULATED = dashed amber ring, slight hologram tint + `SIM` tag. Status is always
icon + text, never color alone. `prefers-reduced-motion` makes characters jump instead of walking.

## Adding things
* New outfit/department: extend `Outfit`/`OUTFIT_BY_DEPT` and the `torso`/`accessory` switches in `characters.ts`.
* New furniture: add a `Prop` kind in `layout.ts` and a case in `propArt()` in `ship.ts`.
* `apps/web/lab/office.html` (dev only, `npm run dev -w @avo/web` → `/lab/office.html`) renders hand-written fixtures for visual checks.
